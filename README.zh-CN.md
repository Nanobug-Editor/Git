# Git for Nanobug

本地候选 0.1.48 使用统一可配置原生 `Editor` 契约（`ui.code_editor ^2`、`editor.layout ^2`），需要提供 `ui.canvas >=1.11`、`editor.virtual >=1.2`、`ui.tree >=1.9` 与 `editor.diff >=1.5` 的配套开发宿主；保留原内容、Undo/Redo 与插件数据。候选使用配套宿主构建，原有固定宿主记录仅用于历史版本。


[English](README.md)

Nanobug 的独立 WASM Git 插件，使用原生界面。左侧为暂存文件树和提交表单，底部为分支树、分页提交拓扑及提交预览。文件比较保留在主编辑区；冲突处理使用独立原生窗口。

当前是初始开发候选包，需要配套的 Nanobug 宿主改动（含 `ui.code_editor` 1.1），尚未发布到市场。比较使用显示层补白，原生编辑会话保留文本与撤销状态。超过布局预算时明确降级为独立滚动；打开原生搜索或代码操作面板时暂停整组对齐，关闭后恢复。

## 构建

需要 Rust 1.95 或更新版本、`wasm32-wasip2` target，以及配套的 Windows x86-64 Nanobug 开发版。宿主通过按内容摘要管理的缓存提供公开 SDK；不要依赖宿主源码路径，也不要复制 SDK 源码。

```powershell
$nanobug = 'C:\Projects\RustProjects\Editor\target\debug\editor-app.exe'
& $nanobug --plugin-cargo ./Cargo.toml check --target wasm32-wasip2
& $nanobug --plugin-cargo ./Cargo.toml test --lib
& $nanobug --plugin-package . --output target/packages
```

打包器同时调用 Cargo 构建 `native/`，并记录原生辅助程序产物的真实摘要。通过 Nanobug 插件管理器安装生成的 `git-0.1.48.zip`。使用已构建包不需要 Rust 或 Cargo；Git 需要已安装，并可由宿主现有工具解析机制找到。

## 行为与权限

0.1.22 在独立插件内保存有容量上限的分支首屏和不可变提交预览。返回已看过的分支直接发布缓存，不启动 Git 子进程。首次选择优先从已加载的提交图投影已知祖先，同时读取有界提交页；等待期间保留画布，只读查询不禁用其他控件。引用 OID／HEAD 变化会使历史缓存失效，过期筛选回执会被拒绝。没有增加宿主 API 或安装权限。

配套宿主在四个方向箭头后显示一个折叠／展开切换按钮：存在隐藏区段时展开全部，否则折叠全部。单段展开与标签保留状态同步反映到同一个按钮。

0.1.20 需要配套宿主的 `ui.tree >=1.4`。选择分支时保留完整提交列表及预览，等新查询完成再替换；状态、引用和提交文件集合的变化通过原子增量更新缓存节点及目录，保留未变化的页、原生选择、展开与滚动状态。文件及完整提交说明一起发布。插件继续独立交付，不增加安装权限。

0.1.19 需要配套宿主的 `editor.diff >=1.4`。比较默认展开，工具栏使用复制到本插件内的资源管理器折叠／展开图标。折叠完全一致区段时两端各保留三行上下文，点击折叠占位行可同步展开双栏／三栏中的单段。文本、原行号、选择与 Undo 仍由原生会话维护，切换标签保留折叠选择；不增加安装权限。

0.1.18 需要配套宿主的 `editor.diff >=1.3`。比较工具栏以左右箭头切换原提交的相邻改动文件，上下箭头跳转当前文件差异，保留中英文悬停提示与可访问名称。首尾禁用对应方向；固定标签保留原 OID、父提交选择与文件顺序，不随日志选择改变。去掉统一视图和同步滚动按钮，默认分栏同步。插件通过公开类型化命令持有文件序列，不增加安装权限。

0.1.17 需要配套宿主的 `ui.tree >=1.3`。首次加载时沿懒页及多级目录展开、选中当前检出分支，不抢焦点，初始历史仍为全部引用。第一条提交自动选中并加载完整文件和说明；主动切换分支筛选时选中该列表首条，后台刷新及显隐保留后续用户选择。改动文件名以新增绿色、删除红色、修改蓝色显示，并提供中英文状态提示。合并提交保留所有父提交变更的并集，不同父版本间状态不一致时标为修改；此视图关闭重命名检测，旧路径删除和新路径新增均保留。

0.1.16 去除历史面板外层空白，为右侧上下两个预览区域分别增加 8px 内容内边距。配套宿主为未指定图标的树节点使用资源管理器的文件夹与文件类型图标；没有菜单项时不显示标题栏菜单按钮。分支分页及原生交互状态保留机制不变。

Git 面板显示分支树、提交行和右侧提交预览。预览上方是改动文件树，下方显示完整提交说明及元信息；选择提交不再打开独立详情窗口。点击改动文件在主编辑区打开只读比较标签：普通提交为父提交／所选提交双栏，合并提交为父提交 1／结果／父提交 2 三栏，多父提交允许明确选择两侧。固定后的标签保留不可变来源，不随预览选择变化；需要 `editor.diff >=1.2`。不显示搜索行、表格头和底部信息栏，拓扑图保留 16px 左侧留白。“更多提交、仓库信息、Stash 列表”从分支树右键菜单打开。

打开单个仓库根目录或 linked worktree 根目录；只打开仓库子目录时明确拒绝。插件使用公开的进程、工作区、文档、UI、定时器和私有存储能力。交互式变基的编辑器辅助程序作为声明的原生依赖，校验产物摘要后安装到插件私有版本目录。

显式暂存和差异块操作管理 Git index；提交复选框独立选择本次提交的整文件。所选文件有原生未保存修改时，要求保存并复核后重试提交；未选文件及其已有暂存内容保留。本地刷新不访问远程；网络操作使用现有 Git 认证配置，插件不保存凭据。

后台本地检查至少间隔 30 秒，用户交互期间继续延后；读取时不禁用控件，无变化时不替换原界面。手动刷新、重新激活、保存文档及 Git 操作完成后仍及时更新。

周期检查没有发现变化时，保留原生控件和已加载的树页。当前用户输入先取消可选的只读检查，再正常处理；真实 Git 变化和错误仍正常发布。暂存树、分支树和提交详情文件树仅在各自来源变化时失效。

0.1.15 需要配套宿主的 `ui.tree >=1.2`。选择分支、暂存／Git 面板显隐以及命令可用性变化仅更新缓存节点信息，不重新加载分支树页；展开、选择和滚动保留在原生树。分支成员／当前分支真正变化仍更新相应数据；只有工作区文件变化时更新 Stash 可用性，不重载分支。安装权限不增加。

支持整文件与差异块暂存、分支、Fetch／Pull／Push、Stash、Merge、Reset、Cherry-pick 和有界的交互式 Rebase。交互式变基支持重排、改说明、Squash、Fixup、Drop，不接受任意 `exec`，不重建合并拓扑。破坏性操作先展示预览，再由用户明确执行；更新已发布历史使用明确预期远程 OID 的 force-with-lease。

二进制和非 UTF-8 冲突提供明确的整版本选择；超出比较或计划上限时显示限制，不应用截断内容。关闭冲突窗口保留原生结果文档及 Undo，不隐式中止 Git 操作。已确认范围与实际验证状态见宿主仓库的 `docs/plugins/specs/git-plugin.md` 和对应验收记录。
